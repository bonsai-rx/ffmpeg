## About

`Bonsai.FFmpeg` provides operators for interfacing with the open source [FFmpeg](https://www.ffmpeg.org/) multimedia framework. The package requires access to a separate FFmpeg installation.

## How to Use

To use `Bonsai.FFmpeg` for visual reactive programming, please install this package using the [Bonsai package manager](https://bonsai-rx.org/docs/articles/packages.html).

## Documentation

For additional documentation and examples, refer to the [official Bonsai documentation](https://bonsai-rx.org/ffmpeg/).
